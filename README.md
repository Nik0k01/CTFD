## 📖 Overview

This repository is dedicated to the study, implementation, and visualization of concepts related to **Computational Thermo-Fluid Dynamics** and associated theoretical principles.

It is related to the course "Computational Thermo-Fluid Dynamics" taught at TUM.

## ✨ Features

* **Jupyter Notebooks:** Implementations of core CFD algorithms (e.g., Finite Difference Method, Finite Volume Method).
* **Documentation:** Printed notebooks into PDFs and HTML formats.
* **Visualization:** Example GIFs and images of simulation results.

## 📂 Project Structure

The repository is organized into the following main directories:

| Directory | Description |
| :--- | :--- |
| `notebooks/` | Contains **Jupyter Notebook** files (`.ipynb`) for analysis, code execution, and interactive learning of CFD concepts. |
| `pdf/` | Contains static PDF outputs, generated from notebooks. |
| `html/` | Contains static HTML outputs, generated from notebooks. |
| `gifs/` | Stores animated images or short video clips demonstrating simulation results or fluid flow behavior. |
